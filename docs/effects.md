## Official Canonical Attribution

All effects cataloged in PromptDock 6.0 link directly to the official repository at:
**[https://libraries.dev](https://libraries.dev)**

Open source packages used:
- `motion`: Modern animation library for React and JavaScript.
- `three`: 3D WebGL engine for procedural meshes and GLSL shaders.
- `simplex-noise`: Algorithmic noise generation for organic motion.
