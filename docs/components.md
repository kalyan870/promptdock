# Component Marketplace Documentation (21st.dev-Inspired)

PromptDock 5.0 features a dedicated visual component discovery catalog inspired by `21st.dev`, providing ready-to-copy React, Tailwind, and Three.js component code.

## Available Component Classes

1. **Split Screen 3D Hero (`comp-hero.svg`)**:
   - Split-screen hero layout featuring Three.js WebGL canvas, floating telemetry chips, and magnetic buttons.
   - Stack: React 19, Three.js, Tailwind CSS.

2. **Dynamic Island Dock Navigation (`comp-navbar.svg`)**:
   - Floating glassmorphism navbar inspired by the Apple Dynamic Island with smooth spring expansion.
   - Stack: Framer Motion, Tailwind CSS.

3. **Interactive Button Suite (`comp-buttons.svg`)**:
   - Border beam light runners, magnetic cursor attraction with damping, and liquid gradient hover glows.
   - Stack: GSAP 3, CSS Keyframes.

4. **3D Perspective Tilt Cards (`comp-cards.svg`)**:
   - Physics-driven card tilt calculating cursor offsets with dynamic specular glare overlays (`--gx`, `--gy`).
   - Stack: CSS 3D Transforms, Vanilla JS.

5. **Glassmorphic Pricing Table (`comp-pricing.svg`)**:
   - Tiered pricing table with interactive monthly/annual switch and highlighted popular tier card.
   - Stack: Tailwind CSS, Framer Motion.

6. **Asymmetrical Bento Grid (`comp-bento.svg`)**:
   - Multi-tile bento layout with live WebGL shader nodes and telemetry sparkline graphs.
   - Stack: CSS Grid, HTML5 Canvas.

7. **AI Copilot Chat Interface (`comp-chat.svg`)**:
   - Streaming markdown chat interface with syntax highlighting and token metrics.
   - Stack: React, Lucide Icons.

8. **Multi-Step Inquiry Form (`comp-forms.svg`)**:
   - Interactive wizard form with reactive validation indicators.
   - Stack: React Hook Form, Zod.

9. **Kinetic Variable Typography (`comp-text.svg`)**:
   - Velocity-skewed typography manipulating CSS font-variation-settings in real time.
   - Stack: CSS Variable Fonts, GSAP.

10. **Three.js 3D Viewport (`comp-3d.svg`)**:
    - Container canvas with orbit controls, inertia dampening, and graceful fallback.
    - Stack: Three.js WebGL.

11. **Mesh Gradient & Starfield Background (`comp-backgrounds.svg`)**:
    - Animated GPU noise shader with floating starfield particle cloud.
    - Stack: GLSL Fragment Shader.
