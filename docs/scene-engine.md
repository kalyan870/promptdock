# PromptDock 8.0 3D Scene Engine Architecture

## Overview

PromptDock 8.0 features a modular, lifecycle-managed Three.js WebGL scene execution architecture driven by `SceneFactory` (`src/engine/scene-factory.ts`) and `PromptEngine` (`src/engine/prompt-engine.ts`).

## Core Principles

1. **Dedicated Procedural Generators**:
   Every one of the 30 visual effects has an isolated generator in `SceneFactory`. There are zero blank placeholders.
2. **Deterministic Geometry Clean-up & Teardown**:
   When switching scenes in the 3D Inspector or unmounting components, `SceneFactory.cleanGroup()` recursively disposes all geometries, materials, maps, and listeners, guaranteeing zero GPU memory leaks.
3. **Continuous Lifecycle Throttling**:
   Off-screen pausing via `IntersectionObserver` and tab visibility handling via `document.visibilitychange` prevent unnecessary GPU cycles when views are inactive.
4. **Scene-Specific AI Prompt Parity**:
   Every visual effect maps its bespoke geometry, shader parameters, kinematic loop, and lighting directly into the canonical 18-point AI build prompt generated by `PromptEngine`.

## Registered Scene Types (30 Visuals)

- **3D Hero Experiences**: `aurora`, `planet`, `abstractTorus`, `spatialGlass`, `kineticType`
- **3D Backgrounds**: `galaxy`, `starfieldWarp`, `neuralNet`, `terrain`
- **Particles and Physics**: `reactiveParticles`, `magneticAttractor`, `curlVortex`, `flowField`
- **3D Product Experiences**: `headphone`, `chronoWatch`, `hardwareTerminal`
- **Motion and Scroll Experiences**: `scrollCameraTrack`, `multiplaneParallax`, `sectionDissolve`
- **3D UI Components**: `tiltCardStack`, `morphingPill`, `magneticButtonMesh`, `borderBeamRunner`
- **Shaders and Materials**: `liquidChromeMesh`, `glassRefractionPrism`, `gooeyCluster`
- **AI and Technology Visuals**: `thinkingOrb`, `neuralGraph`, `voiceRing`, `telemetryGrid`
