# Prompt Library 2.0 Specification

PromptDock 6.0 features a curated catalog of 16 production-tested AI prompts engineered specifically for generating modern, interactive web interfaces.

## Catalog Categories

1. **AI Website Generation**: Autonomous UI builder interfaces with streaming node graphs and canvas previews.
2. **Three.js & WebGL**: Procedural particle fields, low-poly planetary bodies, GLSL liquid chrome shaders.
3. **Dashboards & Telemetry**: High-density real-time metric monitors, glowing SVG sparklines, and status matrices.
4. **Landing Pages & Portfolios**: Scroll-driven storytelling layouts, kinetic typography, and 3D tilt cards.
5. **E-commerce & SaaS**: Spatial product viewers, slide-in checkout drawers, and drag-and-drop kanban boards.
6. **Mobile & Dynamic Islands**: Interactive morphing pills with spring damping physics.

## Prompt Architecture Standard

Every prompt includes:
- **Title**: Descriptive name of the pattern.
- **Category**: Filterable tag classification.
- **Specification**: Complete technical requirements (layout, styling, animations, responsiveness, zero memory leaks).
- **Stack Tag**: Recommended technology combinations (e.g. `Next.js 15, Tailwind, Three.js`).
- **Production Boilerplate**: Copyable implementation code.
