# PromptDock 7.1 — Product Overview

PromptDock 7.1 is a specialized 3D Website Visual Prompt Studio designed for discovering, previewing, customizing, and generating comprehensive AI implementation prompts for creative web development.

## Core Tagline
> **"Discover the visual. Copy the prompt. Build it with AI."**

## Clean 5-Step Visual Workflow
```
STEP 01 — DISCOVER
Explore 30 curated 3D website visual effects across 8 disciplines.
       ↓
STEP 02 — PREVIEW
Inspect and customize the visual in the live real-time WebGL 2.0 viewport.
       ↓
STEP 03 — GENERATE
Create an exhaustive 18-point technical AI implementation prompt incorporating custom parameters.
       ↓
STEP 04 — COPY
Copy and paste the tailored prompt into any AI coding assistant.
       ↓
STEP 05 — BUILD
Generate the website with your chosen AI assistant (Antigravity, Claude, Cursor, ChatGPT).
```

## Key Value Propositions
1. **Curated 3D Visual Gallery**: 30 production-grade 3D website visual effects spanning 8 specialized categories.
2. **Dedicated Scene Factory**: Every visual effect maps to an accurate, distinct WebGL scene implementation rather than generic fallback geometry.
3. **Live WebGL 2.0 Inspector with Live FPS**: Real-time parameter tweaking (color, velocity, density, glow, camera distance, wireframe) that alters the 3D scene instantaneously while measuring real hardware framerates.
4. **Direct Parameter Transfer to Prompt Studio**: Customized Inspector settings are dynamically passed directly into the AI Build Prompt Generator without resetting to defaults.
5. **18-Point Engineering Briefs**: Exhaustive prompts tailored to your target framework (Next.js 15, React Three Fiber, Vanilla Three.js) with explicit codebase preservation instructions.
6. **Multi-Effect Visual Composer**: Combine 2+ compatible 3D visuals with unified requestAnimationFrame loops and harmonized lighting.
