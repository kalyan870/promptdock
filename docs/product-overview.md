# PromptDock 7.0 — Product Overview

PromptDock 7.0 is a specialized 3D Website Visual Prompt Studio designed for discovering, previewing, customizing, and generating comprehensive AI implementation prompts for creative web development.

## Core Tagline
> **"Discover the visual. Copy the prompt. Build it with AI."**

## End-to-End Visual Workflow
```
DISCOVER 3D VISUAL
       ↓
PREVIEW INTERACTIVE EFFECT
       ↓
CUSTOMISE PARAMETERS
       ↓
GENERATE COMPLETE AI PROMPT
       ↓
COPY PROMPT
       ↓
PASTE INTO ANY AI CODING ASSISTANT
       ↓
GENERATE THE WEBSITE
       ↓
RETURN TO PROMPTDOCK
       ↓
GENERATE MODIFICATION PROMPT
       ↓
IMPROVE THE EXISTING WEBSITE
```

## Key Value Propositions
1. **Curated 3D Visual Gallery**: 30+ production-grade 3D website visual effects spanning 8 specialized categories.
2. **Live WebGL 2.0 Inspector**: Real-time parameter tweaking (color, velocity, density, glow, camera distance, wireframe) that alters the 3D scene instantaneously.
3. **18-Point Engineering Briefs**: Exhaustive prompts tailored to your target framework (Next.js, React Three Fiber, Vanilla Three.js) with explicit codebase preservation instructions.
4. **Surgical Modification Studio**: Safe prompt generator for iterating on existing sites without breaking routes, styles, or unrelated components.
5. **Multi-Effect Visual Composer**: Combine 2+ 3D visuals with unified requestAnimationFrame loops and harmonized lighting.
