# Modification Prompt Engine

When developers or clients have already generated a website using an AI assistant (Antigravity, Claude, Cursor, ChatGPT), requesting follow-up changes often leads to catastrophic rewrites or broken features.

The **Modify Existing Website** engine generates surgical instructions ensuring that the coding assistant:
1. **Modifies in-place**: Never rebuilds the entire project from scratch.
2. **Inspects before editing**: Analyzes the directory tree and existing components.
3. **Preserves existing functionality**: Protects unrelated components, routes, and styling.
4. **Applies targeted changes**: Adjusts only the requested parameters (visual, motion, content, responsive, performance).

## Preset Categories
- **Visual**: Vibrant palettes, boosted glow, metallic finishes, glass refraction.
- **Motion**: Cursor parallax, scroll camera journeys, slower elegant rotations, magnetic snap.
- **Content**: Floating secondary geometry, particle auras, dynamic island bars.
- **Responsive**: Touch gesture optimization, particle budget cuts, 2D canvas fallbacks.
- **Performance**: `IntersectionObserver` pause, explicit GPU disposal, instanced meshes.
