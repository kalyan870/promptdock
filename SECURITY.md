# Security Policy

PromptDock takes web security seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within PromptDock, please do not disclose it publicly in an open issue.

Instead, please report vulnerabilities by contacting the maintainer via GitHub Security Advisories or by emailing [kalyan870@users.noreply.github.com](mailto:kalyan870@users.noreply.github.com).

We will investigate and respond to valid security reports within 48 hours.
