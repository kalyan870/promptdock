# Changelog

All notable changes to PromptDock are documented in this file.

## [5.0.0] - 2026-11-08

### Added
- **Visual Presentation Upgrade**: Every major section now displays large, visible preview compositions without requiring modal opening.
- **Split-Screen 3D Hero**: Redesigned hero with headline, tech indicators, and Three.js WebGL canvas overlaid with realistic floating browser preview.
- **21st.dev-Inspired Component Marketplace**: Complete visual component discovery section with 11 component classes, large previews, filter pills, and one-click code copy.
- **Libraries.dev-Inspired Effects Registry**: Creative effects and shader registry with border beams, thinking orbs, liquid chrome, and audio visualizers.
- **Visual Workflow Diagram**: 8-stage interactive pipeline (`workflow-pipeline.svg`) and platform architecture diagram (`architecture-dock.svg`).
- **Showcase Projects**: 8 comprehensive case studies and real interface mockups.
- **Global Command Palette**: `Ctrl + K` quick search across prompts, components, libraries, and resources.
- **Comprehensive Documentation**: Complete `docs/` suite covering architecture, getting started, visual systems, 3D engine, workflow, testing, deployment, and roadmap.
- **53 Production Vector Assets**: High-resolution, Retina-ready SVG assets in `images/`.

### Changed
- Preserved 100% of existing search filtering, favorite saving, and deep-link routing.
- Enhanced 3D card tilt physics with dynamic cursor light tracking and specular reflections.
- Upgraded automated test runner and production build verification script.
